# Secure Coding Challenge Series

## Overview
Document a set of secure coding labs that emphasize identifying, exploiting, and fixing vulnerabilities in application code.

## Methodology
1. **Assessment:** Analyze provided code, identify insecure patterns, and create proof-of-concept exploits.
2. **Remediation:** Refactor code to implement secure patterns and mitigate vulnerabilities.
3. **Verification:** Demonstrate how the updated code prevents the original exploit.

## Repository Layout
- `/src`: Source code for vulnerable and remediated applications.
- `/tests`: Automated test cases that validate vulnerability fixes.
- `/write-ups`: Detailed documentation and lessons learned per challenge.
